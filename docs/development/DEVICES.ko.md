# Z10·Passport 대상 기기 점검

사용자가 지정한 기기: BlackBerry Z10, BlackBerry Passport. 실제 기기 연결이나 화면 실행은 아직 검증하지 않았습니다.

| 항목 | Z10 | Passport |
| --- | --- | --- |
| 화면 픽셀 | 768 × 1280 | 1440 × 1440 |
| 형태 | 세로형 터치 화면 | 정사각형 화면과 물리 키보드 |
| 기본 빌드 | ARMv7 (`armle-v7`) | ARMv7 (`armle-v7`) |
| 이번 예제의 OS 기준 | BB10 10.3.1 이상, 실제 버전 확인 필요 | BB10 10.3.1 이상, 실제 버전 확인 필요 |
| 실제 설치·실행 | 미확인 | 미확인 |

해상도와 디자인 단위는 BlackBerry의 [UI Guidelines](https://developer.blackberry.com/devzone/files/design/bb10/UI_Guidelines_BlackBerry_10.pdf)를 기준으로 했습니다. 동일한 UI의 크기를 픽셀 상수로 고정하지 않고 `ui.du()`와 레이아웃을 사용합니다. 예제는 `bb.cascades 1.4`와 디자인 단위 여백을 사용합니다.

## 기기별 기록할 정보

- 설정에서 확인한 OS 전체 버전과 모델 세부형식.
- 개발 모드 사용 가능 여부, USB/동일 LAN에서 접근 가능한 IP.
- 유효한 디버그 토큰 또는 기존 서명 환경의 유무. 비밀 파일 자체를 채팅이나 저장소에 붙이지 않기.
- 순정/변경 펌웨어 여부. 이 작업에서는 기기를 변경하지 않음.

## 첫 앱 설치 후 확인

- 아이콘 선택 후 첫 화면이 열리고 앱이 즉시 종료되지 않는지.
- `Count` 버튼 입력 시 C++의 카운트가 QML 화면에 반영되는지.
- Z10 세로·가로 방향에서 글자와 버튼이 잘리지 않는지.
- Passport 정사각형 화면에서 여백과 글자 크기가 적절한지.
- 후속 입력 폼에서 Z10 가상 키보드로 가려지는 영역, Passport 물리 키보드 입력·포커스·탐색.
- 최소화·재개·종료 후 다시 시작할 때의 동작. 현재 카운트 예제는 재시작하면 0으로 초기화함.

네트워크·미디어 기능을 추가한 후에는 두 기기에서 TLS, 인증서, 지원 코덱을 실제 서버/파일과 함께 확인합니다. 기본 예제는 네트워크와 미디어 권한을 요청하지 않습니다.
